## Overview

The Value Investing Engine is an independent research project investigating whether fundamental Value Investing principles (Graham, Buffett, Damodaran) can be systematically automated in code—combining balance sheet fundamentals with qualitative business indicators to evaluate risk-adjusted performance against the S&P 500.
